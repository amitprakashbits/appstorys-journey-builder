2

Trigger type

Segment-triggered (audience membership) or event-triggered (an action). This choice changes the fields below it.

3

Trigger event

A single event from the events catalog, chosen through the searchable, category-grouped picker.

Must be an active event
4

Audience

All users, or a droplist of active cohorts only. Cohorts are never created here - an empty state links out to the Cohorts flow.

5

Estimated reach

Recomputes live as trigger/audience change, so the user sees journey size before committing.

6

Simulate & live stats

Reach / delivered / conversions read from a dry-run so the user can gauge the flow before publishing.

7

Entry badge - no Start node

The trigger config from setup rides as a badge on the first node. Entry is simply the node with no incoming edge.

8

Node card

Kind icon + name + editable title, then the 2–3 highest-signal config values. Double-click (or the hover toolbar) opens the editor.

9

Ports & connections

Drag a bottom port to another node's top port to connect. Orthogonal edges; hovering shows flowing packets and a mid-edge "＋" to insert inline.

Rejects cycles & edges into entry
10

Needs-setup & branches

A red "!" flags an unconfigured node. Branching nodes fan into labelled ports (Yes / No, or A/B variants) that connect independently.

Publish blocks orphaned branches
11

Canvas controls

Bottom bar: add step, zoom, fit, snap-to-grid, tidy-up (auto-layout), undo / redo, shortcuts. Full keyboard layer; minimap bottom-right.
